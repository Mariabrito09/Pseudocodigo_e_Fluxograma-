# Pseudocódigo e Fluxograma - Lógica de Programação 🚀

Este repositório contém as atividades desenvolvidas para o curso de **Desenvolvimento de Sistemas no SENAI**. O objetivo principal é exercitar o pensamento lógico e a estruturação de algoritmos através da criação de pseudocódigos e fluxogramas para situações do cotidiano.

---

## 📋 Atividades Realizadas

O projeto aborda a resolução lógica dos seguintes processos:

1.  **Ir ao Trabalho:** Planejamento de trajeto e tomada de decisão.
2.  **Trocar o Pneu de um Carro:** Sequenciamento de passos técnicos e segurança.
3.  **Trocar uma Lâmpada:** Verificação de estado e execução da troca.
4.  **Pegar um Ônibus:** Lógica de horários, rotas e embarque.
5.  **Preparar um Bolo Simples:** Algoritmo de receita com entrada de ingredientes e processamento.

---

## 🛠️ Ferramentas Utilizadas

* **Microsoft Word:** Para a escrita e formatação dos pseudocódigos.
* **Git/GitHub:** Para controle de versão e hospedagem do projeto.
